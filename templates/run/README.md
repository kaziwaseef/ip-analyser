# Analysis run template

Copy this directory's contents to `products/<slug>/markets/<market-id>/runs/<YYYY-MM-DD>-<sequence>/`. Complete the manifest before analysis. Create `inputs/` and `outputs/` on first use.

Save the exact prompts and relevant input snapshots under `inputs/`. Save raw stage results and the challenge output under `outputs/`. Complete analysis tables only for applicable workstreams and explain exclusions in the report.

Keep the original inputs and outputs after finalization. Corrections belong in a dated addendum or a new run, with links to the result they supersede.
