# Decision tickets

The [Build a product IP research and analysis workspace map](ip-workspace/map.md) is the canonical index for this effort. Its child tickets hold questions, discussion, and resolutions.

Read [the local tracker rules](../docs/agents/issue-tracker.md) to find the next open, unblocked, unclaimed ticket. The map intentionally does not duplicate the open-ticket list.

Future product research belongs in `products/`, not in this directory. Create another map only for a distinct effort with its own destination.
