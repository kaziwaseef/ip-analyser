Description

The Rocbolt Security Slot Adapter can be used with the Rocbolt Locking Solution Kit. It is used for laptop or tablet devices that do not have any security slots. This Security Anchor Point can attach to any device using the industrial grade glue for a secure attachment to any metal or ABS Plastic surface or the 3M™ Dual Tape Adhesive Pad. The Rocbolt anchor is made from Zinc Alloy Metal for a reliable and firm attachment – The kit Includes the Anchor Point, Glue & Alcohol Pad and the 3M™ Dual Tape Adhesive Pad. If the user does not want to use the glue, then the 3M™ Dual Tape Adhesive Pad can be used. Simply stick one side of the tape on the adapter disk and then the other side of the tape onto the device. Additionally, it is TAA Compliant, and backed by a 5-year warranty.

Features:
• Compatible with Rocstor locking solution kits.
• The Kit includes an alcohol surface preparation pad and 3M™ Dual Tape Adhesive Pad.
• The Security Slot Adapter is a perfect solution for devices that do not have security slots.
• The permanent adhesive that is included in the kit is industrial grade.
• Dimension Length: 37.5mm Width: 15mm Height: 5.5mm
• Net Weight of the security slot: 12.5 grams
• Total Kit Net Weight: 21.1 grams
• TAA Compliant.
• 5-year warranty
